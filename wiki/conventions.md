# Wiki Conventions

Style guide and naming conventions for this wiki. Co-evolved by human and agent.

## Naming

- Use the most specific common name for entities (e.g., "GPT-4" not "OpenAI's GPT-4 model")
- Concepts use lowercase unless they're proper nouns (e.g., "attention mechanism" not "Attention Mechanism")
- One canonical name per entity — list aliases in the page body

## Page Structure

- Keep pages between 200-500 words
- Lead with a one-paragraph summary
- Use `## See Also` as the final section for cross-links
- Date any claim that might become stale: "As of August 2026, ..."

## Tagging

- Use lowercase tags in frontmatter
- Prefer broad categories: `machine-learning`, `architecture`, `tooling`

## Language

- Write in English unless the user specifies otherwise
- Use active voice and present tense for current facts
- Use past tense for historical events
