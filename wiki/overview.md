# Wiki Overview

This wiki is a persistent, interlinked knowledge base maintained by an LLM agent. It compiles knowledge from raw sources into structured, cross-referenced pages.

## How to Use

1. Drop source documents into `sources/`
2. Ask the agent to ingest them: `/wiki ingest`
3. Query the compiled knowledge: `/wiki query <question>`
4. Periodically lint for health: `/wiki lint`
